# pnpm-monorepo

This directory contains the pnpm workspace:

- `apps/app`: the Next.js app
- `apps/collab`: the wiki collaboration server
- `apps/lambda`: the AWS Lambda functions
- `apps/playwright`: the end-to-end tests (see [apps/playwright/README.md](./apps/playwright/README.md))
- `apps/scripts`: import, migration and content-generation scripts (see [apps/scripts/README.md](./apps/scripts/README.md))
- `packages/`: the shared workspace packages

For the requirements and the setup steps, see [docs/setup-local-machine.md](../docs/setup-local-machine.md).
